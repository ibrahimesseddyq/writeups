# CTF writeups archive

Archived copies of public CTF writeups, organized as `ctf/edition/challenge.md`.
359 writeups across 117 CTF editions.

**These writeups are not mine.** Each file names its original author and links the original writeup at the top — all credit belongs to them.
The texts were collected from public CTFtime writeups via the [ctfsearch-data](https://github.com/KevinL10/ctfsearch-data) dataset.
If you are an author and want your writeup removed, please open an issue.

Linked from [ctf42.online](https://ctf42.online), a CTF challenge archive.
